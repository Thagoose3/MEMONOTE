# MEMONOTE Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Windows desktop note app with two modes — rich notes (images, code, copy fields, `[[links]]`) and a board (note cards, connecting arrows, freehand pen) — storing everything as files in a user-chosen folder.

**Architecture:** Electron main process owns the vault on disk (atomic JSON writes, image assets, file watcher) and exposes it through one `Storage` interface over IPC via the preload bridge. The React renderer never touches the filesystem; it keeps an in-memory index (metadata, MiniSearch, backlinks), edits notes with TipTap and boards with React Flow. Pure logic (links, search, conflicts, eraser hit-test, history) lives in plain TS modules with unit tests.

**Tech Stack:** Electron + electron-vite + React + TypeScript, TipTap (+ lowlight), @xyflow/react, perfect-freehand, MiniSearch, Zustand, chokidar, ulid, Vitest, Playwright (`_electron`), electron-builder (NSIS).

**Spec:** `docs/superpowers/specs/2026-11-13-memonote-design.md` (Thai). Read it before starting any task.

## Global Constraints

- Windows 11 only. Node 24 is installed; **no native npm modules** (no `sharp`, no `better-sqlite3`) — use Electron `nativeImage` for image work.
- **No network access** except the user clicking "download" on a remote image. Renderer CSP (production): `default-src 'self'; img-src 'self' memo-asset: data: blob:; style-src 'self' 'unsafe-inline'; connect-src 'self'`.
- **No login, no app lock, no encryption.** Copy-field values are shown in plain text.
- All UI copy is Thai. Font stack: `"Segoe UI", "Leelawadee UI", "Noto Sans Thai", sans-serif`.
- Vault layout exactly: `notes/<id>.json`, `boards/<id>.json`, `assets/<sha256>.<ext>`, `assets/.thumbs/<sha256>.<ext>`, `vault.json`, `.trash/`.
- IDs are ULIDs. Titles may repeat. Folders are one level deep.
- Autosave: debounce **500 ms**; every write is atomic (write `<file>.tmp`, then rename).
- Images: longest side > **4000 px** is downsized to 4000 on save (GIF stored as-is). Board thumbnails max side **400 px**.
- Remote images pasted from the web are never auto-loaded.
- No sidebar. Top bar: left `☰` + breadcrumb, center mode switch `[ โน้ต | กระดาน ]`, right `🔍` then native window controls (`titleBarOverlay`, height 40). Note content max width ~760 px. Hit targets ≥ 32 px. Light/dark follows system.
- Target scale: ≤ ~5,000 notes, ≤ ~2 GB images. Metadata + search index load at startup; note content loads on open.
- Test hooks: env `MEMONOTE_VAULT` (vault path, skips chooser) and `MEMONOTE_CONFIG_DIR` (app config dir) are honored by main.

## Review Focus

1. **Closing the app < 500 ms after typing** — the last edit must be on disk (flush on close). Test in Task 7.
2. **Pasting a huge screenshot (e.g. 8000×5000 PNG)** — UI stays responsive, stored image ≤ 4000 px, thumbnail exists. Tests in Task 3 and Task 8.
3. **A corrupt or half-written JSON file in `notes/`** (hand-edited, sync glitch) — app starts, skips it, reports it, never overwrites it. Test in Task 2.
4. **Deleting a note that is `[[linked]]` or on a board** — link renders as "โน้ตถูกลบ", board card shows "โน้ตถูกลบ", nothing crashes; restoring from trash brings both back. Tests in Task 10 and Task 12.
5. **Thai text with no spaces** (e.g. "บัญชีทดสอบร้านกาแฟ") — searching "ร้านกาแฟ" finds it. Test in Task 6.

## Shared types (defined in Task 1, used everywhere)

```ts
// src/shared/types.ts
export type DocNode = { type: string; attrs?: Record<string, unknown>; content?: DocNode[]; text?: string; marks?: { type: string; attrs?: Record<string, unknown> }[] };
export interface Note { id: string; title: string; folder: string | null; created: number; updated: number; content: DocNode; conflict?: boolean }
export interface NoteMeta { id: string; title: string; folder: string | null; created: number; updated: number; text: string; linkIds: string[]; firstImage: string | null; conflict?: boolean }
export type StrokePoint = [x: number, y: number, pressure: number];
export type PenSize = 'S' | 'M' | 'L';               // 4 / 8 / 14 px
export type BoardNode = { id: string; x: number; y: number; w?: number; h?: number } & (
  | { kind: 'note'; noteId: string }
  | { kind: 'text'; text: string }
  | { kind: 'image'; file: string }
  | { kind: 'stroke'; points: StrokePoint[]; color: string; size: PenSize });
export interface BoardEdge { id: string; from: string; to: string; label?: string; color: EdgeColor }
export type EdgeColor = 'gray' | 'blue' | 'green' | 'red';
export interface Board { id: string; title: string; created: number; updated: number; nodes: BoardNode[]; edges: BoardEdge[] }
export interface BoardMeta { id: string; title: string; updated: number }
export interface Folder { id: string; name: string }
export interface VaultFile { version: 1; folders: Folder[] }
export interface AssetRef { file: string; width: number; height: number }   // file = "<sha256>.<ext>"
export interface ListResult<T> { items: T[]; broken: string[] }             // broken = file names that failed to parse
export type ExternalChange = { kind: 'note' | 'board'; id: string; change: 'changed' | 'removed' };
export interface Storage {
  vault: { current(): Promise<string | null>; choose(): Promise<string | null>; readFile(): Promise<VaultFile>; writeFile(v: VaultFile): Promise<void> };
  notes: { listMeta(): Promise<ListResult<NoteMeta>>; read(id: string): Promise<Note>; save(n: Note): Promise<NoteMeta>; trash(id: string): Promise<void>; restore(id: string): Promise<void>; listTrash(): Promise<NoteMeta[]> };
  boards: { list(): Promise<ListResult<BoardMeta>>; read(id: string): Promise<Board>; save(b: Board): Promise<void>; trash(id: string): Promise<void> };
  assets: { saveImage(bytes: Uint8Array, mime: string): Promise<AssetRef>; downloadImage(url: string): Promise<AssetRef> };
  onExternalChange(cb: (e: ExternalChange) => void): () => void;
  onFlushRequest(cb: () => Promise<void>): () => void;
}
```
Asset URLs in the renderer: `memo-asset://a/<file>` and `memo-asset://t/<file>` (thumbnail).
