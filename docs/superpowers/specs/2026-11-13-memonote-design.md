# MEMONOTE — เอกสารออกแบบ

วันที่: 2026-11-13
สถานะ: อนุมัติแล้ว (2026-11-13)

## 1. แอพนี้คืออะไร และทำไม

แอพจดโน้ตบน Windows แบบ Notepad ที่ใส่รูปได้ ผู้ใช้เป็นคนเขียนเว็บ ใช้โน้ตเป็นที่พักของที่ก๊อปมาวาง (ข้อความ โค้ด รูป)
และเก็บบัญชี/รหัสทดสอบของเว็บที่กำลังพัฒนา อยากโยงเส้นความสัมพันธ์ระหว่างของต่างๆ ได้ด้วย

แอพมี 2 โหมด:
- **โหมดโน้ต** — เขียนโน้ตแบบปกติ ลิงก์ไปโน้ตอื่นด้วย `[[ชื่อโน้ต]]`
- **โหมดกระดาน** — ลากโน้ตมาวางเป็นกล่องบนกระดานกว้าง แล้วลากเส้นโยงกัน

## 2. เป้าหมาย / สิ่งที่ไม่ทำ / สิ่งที่ถือว่าล้มเหลว

**เป้าหมาย**
- วางข้อความ โค้ด และรูปได้เร็ว (Ctrl+V, ลากไฟล์มาวาง) ไม่ต้องจัดรูปแบบเอง
- เก็บรหัสทดสอบได้ ก๊อปคลิกเดียว
- ค้นหาเจอเร็ว
- โยงเส้นระหว่างโน้ตได้ทั้ง 2 โหมด
- ข้อมูลอยู่ในเครื่อง เป็นไฟล์ในโฟลเดอร์ สำรองง่ายด้วยการก๊อปโฟลเดอร์

**สิ่งที่ไม่ทำในเวอร์ชันแรก**
- iPad / มือถือ / เว็บ (แต่แยกชั้นเก็บข้อมูลไว้ให้เปลี่ยนได้ภายหลัง)
- ซิงค์ในตัว (ผู้ใช้วางโฟลเดอร์ไว้ใน OneDrive เองได้)
- หน้ากราฟอัตโนมัติจาก `[[ ]]`
- แก้ไขพร้อมกันหลายคน, ระบบบัญชีออนไลน์
- export เป็น Markdown/PDF

**ถือว่าล้มเหลว แม้จะทำงานได้**
- ข้อมูลหาย หรือไฟล์เสียเมื่อปิดแอพกลางคัน
- วางรูปแล้วแอพค้าง หรือโน้ตที่มีรูปเยอะเปิดช้า

## 3. ข้อจำกัด

- Windows 11, เครื่องมี Node 24 และ git ไม่มี Rust
- ใช้ภาษาไทยได้เต็มที่ (ฟอนต์, การค้นหาคำไทย)
- ไม่ส่งข้อมูลใดๆ ออกเน็ต

## 4. แนวทางที่พิจารณา

| แนวทาง | ข้อดี | ข้อเสีย |
|---|---|---|
| **Electron + React (เลือก)** | ใช้ Node ที่มี, เว็บเทคที่ผู้ใช้อ่านออก, เก็บเป็นไฟล์จริงในเครื่อง | โปรแกรมใหญ่ ~100MB |
| Tauri | โปรแกรมเล็ก | ต้องลง Rust + build tools เพิ่ม |
| เว็บแอพในเบราว์เซอร์ | ไม่ต้องติดตั้ง | ข้อมูลหายถ้าล้างเบราว์เซอร์, ถ้าขึ้นเน็ตต้องทำระบบล็อกอิน |

ผู้ใช้เลือก Electron เหตุผล: เก็บรหัสและรูปเยอะ ไฟล์ในเครื่องชัวร์และปลอดภัยสุด

## 5. ส่วนที่ตกลงกันแล้ว

- Windows desktop ด้วย Electron
- 2 โหมด: โน้ต (ลิงก์ `[[ ]]`) + กระดาน (กล่อง + เส้น)
- **ไม่มีล็อกอิน ไม่มีล็อกแอพ ไม่มีการเข้ารหัส** — ผู้ใช้เก็บแค่รหัสทดสอบทั่วไป ไม่ใช่รหัสจริง
- ช่องก๊อปด่วน: ชื่อ + ค่า + ปุ่มก๊อป (ไม่ซ่อนค่า)
- บล็อกโค้ดมีสีไฮไลต์
- เก็บข้อมูลในเครื่อง ไม่ขึ้นเน็ต

## 6. รายละเอียดการออกแบบ (ข้อเสนอของ Claude)

### เทคโนโลยี
- Electron + Vite + React + TypeScript (ใช้ `electron-vite`)
- Editor: **TipTap** (ProseMirror) — รองรับรูป, บล็อกโค้ด (`lowlight`), node กำหนดเองได้
- กระดาน: **React Flow** (`@xyflow/react`) — pan/zoom, ลากเส้นระหว่าง node, รองรับทัชในตัว
- ค้นหา: **MiniSearch** ในหน่วยความจำ ตัดคำไทยด้วย `Intl.Segmenter`
- แพ็กเป็นตัวติดตั้งด้วย `electron-builder` (NSIS)

### หน้าตา
**ผู้ใช้ตัดสินใจ:** ไม่มีแถบข้าง ทุกอย่างอยู่แถบบน และปุ่มสลับโหมดอยู่ตรงกลางด้านบน
(อ้างอิงความรู้สึก: เรียบ โล่ง พื้นที่ทำงานเต็มจอ แบบแอพกระดานวาดมินิมอล)

โหมดโน้ต:
```
┌─────────────────────────────────────────────────────────────┐
│ ☰  เว็บร้าน / บัญชีเทส       [ โน้ต | กระดาน ]     🔍   ─ □ ✕ │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│        บัญชีเทส                                              │
│        ข้อความ... [[UI ร่าง]]                                 │
│        [รูปที่วาง]                                            │
│        ┌ 🔑 admin password ─────────── •••• 👁 📋 ┐         │
│        └─────────────────────────────────────────┘         │
│        ```js  โค้ดมีสี  ```                                   │
│        ── ลิงก์มาจาก: เว็บร้าน ──                              │
└─────────────────────────────────────────────────────────────┘
```
โหมดกระดาน:
```
┌─────────────────────────────────────────────────────────────┐
│ ☰  กระดาน: เว็บร้าน          [ โน้ต | กระดาน ]     🔍   ─ □ ✕ │
├─────────────────────────────────────────────────────────────┤
│        ┌────────┐         ┌──────────┐                      │
│        │เว็บร้าน │────────▶│ บัญชีเทส  │                      │
│        └────────┘         └──────────┘                      │
│                                                             │
│ 100%   [ ↖ ✋ ✏ ปากกา ⌫ ยางลบ 📝โน้ต T 🖼 ↗ เส้นโยง ]          │
└─────────────────────────────────────────────────────────────┘
```
- **แถบบน**: ซ้าย ☰ + ตำแหน่งปัจจุบัน (โฟลเดอร์ / ชื่อโน้ต หรือชื่อกระดาน) คลิกชื่อเพื่อเปลี่ยนชื่อได้ · กลาง ปุ่มสลับโหมด · ขวา 🔍 ค้นหา แล้วปุ่มย่อ/ขยาย/ปิดของ Windows
- หน้าต่างไม่มีกรอบ title bar ของ Windows แถบบนทำหน้าที่แทน ใช้ `titleBarOverlay` ของ Electron ให้ปุ่ม ─ □ ✕ เป็นของระบบจริง ลากแถบบนเพื่อย้ายหน้าต่างได้ *(Claude ตัดสินใจ)*
- **☰ เปิดแผงรายการ** ลอยทับจากซ้าย (ปิดอยู่เป็นค่าเริ่มต้น ปิดเองเมื่อเลือกเสร็จหรือคลิกข้างนอก): โน้ตใหม่ / กระดานใหม่, โฟลเดอร์ + รายการโน้ต (หรือรายการกระดานในโหมดกระดาน), ถังขยะ, ตั้งค่า *(Claude ตัดสินใจ)*
- **🔍 / Ctrl+P** เปิดช่องค้นหากลางจอ เป็นทางหลักในการเปิดโน้ต
- **หน้าเริ่มต้น** (ยังไม่ได้เปิดโน้ตไหน): ปุ่มโน้ตใหม่ (Ctrl+N), เปิดโฟลเดอร์ vault, รายการโน้ตล่าสุด *(Claude ตัดสินใจ)*
- เนื้อหาโน้ตอยู่กลางจอ กว้างไม่เกิน ~760px อ่านง่าย
- ปุ่มและจุดลากเส้นขนาดอย่างน้อย 32px
- ธีมสว่าง/มืด ตามระบบ

### ที่เก็บข้อมูล (vault)
ผู้ใช้เลือกโฟลเดอร์ตอนเปิดครั้งแรก (จำไว้ใน config ของแอพ)
```
<vault>/
  notes/<id>.json        # { id, title, folder, created, updated, content: TipTap JSON }
  boards/<id>.json       # { id, title, nodes[], edges[] }
  assets/<hash>.<ext>    # รูป ตั้งชื่อตาม SHA-256 รูปซ้ำเก็บไฟล์เดียว
  vault.json             # { version, folders[] }
```
- `id` = ULID, ชื่อโน้ตซ้ำกันได้
- โฟลเดอร์มีชั้นเดียวในเวอร์ชันแรก
- **บันทึกอัตโนมัติ**: debounce 500ms หลังพิมพ์ เขียนไฟล์แบบ atomic (เขียน `.tmp` แล้ว rename) กันไฟล์เสีย
- ทุกการอ่าน/เขียนผ่าน interface `Storage` เดียว (main process ผ่าน IPC) — ทำ iPad ภายหลังเปลี่ยนแค่ตัวนี้
- ถ้าไฟล์ในโฟลเดอร์ถูกแก้จากข้างนอก (เช่น OneDrive ซิงค์): ใช้ file watcher (`chokidar`) ดูโฟลเดอร์ ถ้าโน้ตที่ไม่ได้เปิดอยู่เปลี่ยน ให้โหลดใหม่เงียบๆ
  ถ้าโน้ตที่เปิดอยู่และ**มีการแก้ที่ยังไม่บันทึก** เปลี่ยนจากข้างนอก → ไม่เขียนทับ ให้เก็บฉบับของเราเป็นโน้ตใหม่ชื่อ "<ชื่อ> (สำเนาขัดแย้ง)" แล้วโหลดฉบับจากดิสก์ (ไม่มีข้อมูลหาย) *(Claude ตัดสินใจ)*
  ไฟล์ขัดแย้งที่ OneDrive สร้างเอง (ชื่อลงท้าย `-ชื่อเครื่อง`) ที่มี id ซ้ำ ให้โหลดเป็นโน้ตแยกพร้อมป้าย "สำเนาขัดแย้ง" *(Claude ตัดสินใจ)*
- **ขนาดที่รองรับ**: ออกแบบสำหรับโน้ตไม่เกินราว 5,000 ไฟล์ รูปรวมไม่เกินราว 2GB โหลด metadata + ดัชนีค้นหาทั้งหมดตอนเปิดแอพ เนื้อหาโน้ตโหลดเมื่อเปิด กล่องรูปบนกระดานใช้ภาพย่อ (`assets/.thumbs/`) *(Claude ตัดสินใจ — การใช้งานส่วนตัว)*

### โหมดโน้ต
- **วางรูป**: Ctrl+V จาก clipboard หรือลากไฟล์รูปมาวาง → บันทึกลง `assets/` → แทรกเป็น node รูป ย่อ/ขยายได้ รูปใหญ่กว่า 4000px ให้ย่อเก็บ
- **วางข้อความ**: วางจากเว็บเก็บรูปแบบพื้นฐาน (หัวข้อ ตัวหนา ลิสต์ ลิงก์ ตาราง) Ctrl+Shift+V วางเป็นข้อความล้วน
- **รูปจากเว็บที่ติดมากับข้อความ** (`<img src="https://...">`): ไม่โหลดอัตโนมัติ แสดงเป็นกล่องแทนที่ "รูปจากเว็บ — กดเพื่อดาวน์โหลด" กดแล้ว main process ดาวน์โหลดเก็บลง `assets/` renderer ตั้ง CSP บล็อกการเชื่อมต่อเน็ตทั้งหมด *(Claude ตัดสินใจ)*
- **บล็อกโค้ด**: พิมพ์ ``` หรือวางโค้ด เลือกภาษาได้ มีปุ่มก๊อป
- **ช่องก๊อปด่วน (copy field)**: แทรกจากเมนู `/ก๊อป` หรือ Ctrl+Shift+K เป็นแถว ชื่อ + ค่า + 📋 กดแล้วก๊อปค่า ขึ้น "ก๊อปแล้ว" แป๊บนึง ใช้กับ user/password ทดสอบ, URL, token ทดสอบ ค่าแสดงตรงๆ ไม่ซ่อน
- **ลิงก์ `[[ ]]`**: พิมพ์ `[[` แล้วขึ้นรายการโน้ตให้เลือก เก็บเป็น id (เปลี่ยนชื่อโน้ตแล้วลิงก์ไม่พัง) คลิกเพื่อเปิด ถ้าพิมพ์ชื่อที่ยังไม่มี ให้สร้างโน้ตใหม่ได้
- **ลิงก์ย้อนกลับ**: ท้ายโน้ตแสดงโน้ตที่ลิงก์มาหา
- **ค้นหา**: ค้นทั้งชื่อและเนื้อหา (รวมช่องก๊อปด่วน) ผลลัพธ์อัปเดตขณะพิมพ์ Ctrl+P เปิดค้นหาด่วน
- เมนูคลิกขวาที่โน้ต: เปลี่ยนชื่อ, ย้ายโฟลเดอร์, ลบ (ย้ายไปถังขยะ `<vault>/.trash/` ไม่ลบถาวร)

### โหมดกระดาน
- มีได้หลายกระดาน
- ชนิดกล่อง: **โน้ต** (อ้างอิงโน้ตจริง แสดงชื่อ + ตัวอย่างเนื้อหา/รูปแรก ดับเบิลคลิกเปิดในโหมดโน้ต), **ข้อความสั้น** (พิมพ์บนกระดานเลย), **รูป** (วาง/ลากรูปลงกระดาน)
- **แถบเครื่องมือลอยด้านล่างกลางจอ**: เลือก, เลื่อนกระดาน, ปากกา, ยางลบ, เพิ่มโน้ต, ข้อความ, รูป, เส้นโยง · มุมซ้ายล่างแสดง % ซูม · มี undo/redo (Ctrl+Z / Ctrl+Y)
- **ปากกา (ผู้ใช้ขอ)**: วาดมือเปล่าบนกระดาน ใช้ `perfect-freehand` ให้เส้นนุ่ม รองรับแรงกดถ้าใช้ปากกาแท็บเล็ต (Pointer Events)
  - เลือกสีได้ ~8 สี และความหนา S / M / L — แผงเลือกโผล่เมื่อเลือกเครื่องมือปากกา
  - แต่ละเส้นที่วางเสร็จเป็น 1 ชิ้นบนกระดาน เก็บเป็นจุดใน `boards/<id>.json` คลิกเลือก ย้าย ลบได้เหมือนกล่องอื่น ลากคลุมเพื่อเลือกหลายชิ้นได้
  - **ยางลบ**: ลากผ่านเส้นที่วาด เส้นนั้นหายทั้งเส้น (ไม่ลบบางส่วน) ยางลบไม่ลบกล่องโน้ตหรือเส้นโยง
  - เส้นที่วาดเป็นภาพประกอบ ไม่ใช่เส้นโยงระหว่างกล่อง (เส้นโยงยังใช้เครื่องมือเส้นโยง)
  - *(Claude ตัดสินใจ: รายละเอียดสี/ขนาด/ยางลบทั้งเส้น)*
- เพิ่มกล่องโน้ต: กดปุ่ม "โน้ต" แล้วเลือกจากช่องค้นหา (หรือสร้างโน้ตใหม่) กล่องวางตรงกลางจอ หรือลากจากแผง ☰ มาวาง
- เส้น: ลากจากจุดขอบกล่องหนึ่งไปอีกกล่อง มีหัวลูกศร ใส่ป้ายข้อความได้ เลือกสีได้ไม่กี่สี
- pan (ลากพื้นที่ว่าง/ล้อเมาส์), zoom (Ctrl+ล้อ), ย่อขนาดกล่องได้
- ปุ่ม "เพิ่มโน้ตที่ลิงก์กันมาด้วย": เลือกกล่องโน้ต แล้วดึงโน้ตที่ `[[ ]]` ถึงมาวางพร้อมเส้นให้อัตโนมัติ (เชื่อม 2 โหมดเข้าหากัน)
- เส้นบนกระดานแยกจาก `[[ ]]` — ลบเส้นไม่ลบลิงก์ในโน้ต

### ทดสอบ
- Unit test ชั้น Storage (atomic write, รูปซ้ำ, ไฟล์ขัดแย้ง), parser ลิงก์/backlink, ค้นหาคำไทย — ใช้ Vitest
